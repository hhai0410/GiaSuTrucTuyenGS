# private-uploads

Vị trí dự kiến trên máy phát triển cho tệp người dùng tải lên cần kiểm soát quyền. Nằm ngoài wwwroot. Dữ liệu thực bị Git bỏ qua; môi trường triển khai cần cấu hình nơi lưu bền vững riêng.

Đây là thư mục khung; README này giải thích mục đích và giúp Git lưu lại thư mục khi chưa có mã nguồn.
